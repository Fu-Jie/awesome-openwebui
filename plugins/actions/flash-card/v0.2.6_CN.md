# v0.2.6 版本发布说明

## 概述

本补丁更新了闪记卡在 OpenWebUI 0.11+ Action 返回值流程中的兼容性。成功生成卡片后现在返回内联 HTML 响应，使 OpenWebUI 能够通过 Rich UI embed 事件显示生成的卡片。

## 新功能

- 为 OpenWebUI 0.11+ 的成功生成流程增加直接 Rich UI embed 支持。

## 问题修复

- 修复卡片生成成功但不会出现在聊天界面的问题。
- 移除新版 OpenWebUI 不再持久化或渲染的 fenced HTML 消息修改方式。
- 为英文和中文 Action 实现增加回归测试。

## 迁移说明

- 本版本面向 OpenWebUI 0.11+ 的 Action 返回值协议。升级 OpenWebUI 后请重新安装或更新 Action。
- 参数校验和错误流程仍返回原有的 Action body，并保留现有状态提示。

## 文档

- 英文和中文插件 README、文档页面及 Action 索引版本徽章已同步为 v0.2.6。
