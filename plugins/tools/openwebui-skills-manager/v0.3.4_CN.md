# OpenWebUI Skills Manager v0.3.4 版本发布说明

本补丁版本恢复了 Skills Manager 对 OpenWebUI 0.11.1 及更高版本的兼容，同时保留对旧版 SkillsTable API 的支持。

### 问题修复
- 当 `get_skills_by_user_id()` 不可用时，改用 `Skills.get_skills(user_id=...)`。
- 保留现有的用户范围只读筛选，避免无用户范围的技能查询。

### 测试
- 增加旧版和当前 SkillsTable API 的回归测试。
- 增加测试，确保当前 API 始终携带用户 ID 调用。

### 迁移说明
- 无需修改配置。插件继续兼容代码所支持的 OpenWebUI 0.9.x 至 0.11.3 API 形态。
